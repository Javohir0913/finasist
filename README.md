# PROFIT DIVIDER — Financial Platform

Профессиональная финансовая веб-платформа для производственного предприятия
ООО «PROFIT DIVIDER», построенная на базе бухгалтерского Excel-отчёта (48 листов).

**Fintech-minimalism · dark premium UI · real-time · RBAC**

## Стек

| Слой | Технологии |
|------|-----------|
| Backend | FastAPI · async SQLAlchemy 2 · PostgreSQL · JWT · WebSocket |
| Frontend | React + TypeScript · Vite · TailwindCSS · Recharts |
| Инфраструктура | Docker Compose (db + backend + frontend/nginx) |

## Запуск (одна команда)

```bash
docker compose up --build
```

- Frontend:  http://localhost:3000
- Backend API / Swagger:  http://localhost:8000/docs
- PostgreSQL:  localhost:5434 (finasist / finasist)

Схема обновляется автоматически: при старте недостающие колонки добавляются
(`app/migrate.py`), а справочники дополняются идемпотентным сидом — введённые
данные при этом не затрагиваются.

Супер-администратор создаётся автоматически:

```
Email:  admin@profitdivider.uz
Пароль: Admin12345!
```

## Возможности

- **Дашборд** — KPI (поступления/расходы/прибыль/дебиторка-кредиторка), графики Cash Flow
  и структуры расходов, живая лента событий. Переключатель **сум / $** и выбор периода:
  денежные обороты пересчитываются по курсу сделки, складские остатки — по курсу
  на конец периода.
- **Банк и Касса** — операции прихода/расхода в UZS/USD с авто-конвертацией по курсу,
  реквизиты выписки (счёт, № документа, МФО, корреспондент, назначение по кодировке).
- **Отчёты** — ОФР (Форма №2 целиком: от выручки до чистой прибыли, включая финансовую
  деятельность и курсовые разницы) и свод по подразделениям; Баланс (Форма №1 с кодами
  счетов и колонками «на начало» / «на конец»); Cash Flow по разделам — операционная,
  инвестиционная, финансовая — с разрезом БАНК/КАССА и остатками на начало и конец;
  ВСЕГО расходы (БАНК/КАССА/ВСЕГО × UZS/USD); остатки денег по дням и счетам;
  курсовая разница; налоги; займы; себестоимость ГП; обороты склада и продукции.
- **Склад по объектам** — остаток и средняя цена ведутся отдельно по каждой дробилке
  (Махстон, Турк, Жби): списание и себестоимость считаются по цене своего объекта.
- **Настраиваемая классификация** — у каждой статьи расходов задаётся строка ОФР,
  у каждого кода ДДС — раздел отчёта; отчёты перестраиваются без правки кода.
- **Ведомости Дт-Кт** — отдельные ведомости, как листы книги: поставщики, покупатели,
  СЕЙФ, услуги, зарплата, РБП, офис, займы, прочие.
- **Готовая продукция / Сырьё и запчасти** — номенклатура, входящие остатки,
  средняя себестоимость (moving average), обороты склада.
- **Зарплата** — расчёт по методике листа «Зарплата»: дни и сверхурочные, начисления
  (оклад, надбавка, питание, премия, бензин), удержания (НДФЛ, ИНПС, питание, алименты,
  штраф), выплаты (аванс, касса, карта), долг на начало и конец, свод по объектам.
- **Excel** — выгрузка всех отчётов одной книгой и любого реестра отдельно;
  загрузка операций, прихода и продаж из .xlsx с предварительной проверкой файла.
- **Входящие сальдо** — по контрагентам, складам, банковским счетам, кассам и займам:
  система стартует не с нуля, а с фактических остатков на дату начала учёта.
- **Real-time** — любое изменение мгновенно рассылается всем клиентам через WebSocket
  (тосты + автообновление таблиц и дашборда).

Все сальдо (Дт-Кт, склад, себестоимость) считаются заново из первичных документов,
поэтому правка или удаление любой строки корректно пересчитывает все отчёты.

## Управление доступом (RBAC)

Всё контролирует **супер-администратор**:

- Создаёт роли и вручную назначает **гранулярные права** (модуль × действие: просмотр,
  создание, изменение, удаление, экспорт) через матрицу доступа.
- Новые роли и пользователи **не имеют прав по умолчанию** — доступ выдаётся явно.
- Пользователь-**поставщик** или **заказчик** привязывается к своей организации и видит
  только свои операции.
- Пользователей и роли можно включать/отключать, редактировать и удалять.

Готовые примеры ролей: Администратор, Бухгалтер, Поставщик, Заказчик, Наблюдатель, Без доступа.

## Структура

```
finasist/
├── docker-compose.yml
├── backend/            # FastAPI приложение
│   └── app/
│       ├── main.py         # приложение + WebSocket + старт/сид
│       ├── models.py       # SQLAlchemy модели
│       ├── security.py     # JWT + проверка прав (require)
│       ├── permissions.py  # каталог прав
│       ├── ledger.py       # Дт-Кт: сальдо из первичных документов
│       ├── migrate.py      # авто-добавление недостающих колонок
│       ├── seed.py         # супер-админ + справочники из Excel (идемпотентно)
│       └── routers/        # auth, users, roles, organizations, transactions,
│                           # reports, exports, imports, payroll, inventory, ...
└── frontend/           # React + Vite + Tailwind
    └── src/
        ├── pages/          # Dashboard, Reports, Ledgers, Transactions, Payroll, ...
        ├── components/     # Layout, ui-kit, ImportModal
        ├── lib/            # period (глобальный период + выгрузки), format, nav
        └── store/          # auth + realtime
```

## Разработка без Docker

```bash
# backend
cd backend && pip install -r requirements.txt
uvicorn app.main:app --reload   # нужен PostgreSQL, задайте DATABASE_URL

# frontend
cd frontend && npm install && npm run dev   # http://localhost:5173
```
